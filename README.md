# GoSports 排球

Switch Sports 风格的 2v2 卡通排球（Godot 4.7）。支持 **键鼠 / 手柄 / 手机触屏**，单人 / 双人合作 / 双人对决。

```
godot --path .                 # 运行（主场景 scenes/main.tscn）
```

* 设计与实现说明：[docs/DESIGN.md](docs/DESIGN.md)
* 快速试玩：开始比赛 → 选角色 → **J / 鼠标左键** 击球，**K / 右键** 跳跃，**L** 扑救，鼠标指向对方场地瞄准。
* Windows 成品：`build/windows/GoSports.exe`（`Project → Export → Windows Desktop`）
